# Founder GitHub references — 4 market-prediction projects (2026-11-23)

Research-only source audit of four public GitHub repositories shared as reference screenshots. **Do not treat public availability as a license to copy model code or prices.** No external repository has been starred/forked/merged here, no vendor source or model weights imported, and no external data was used in a learning study.

| Repository | Source evidence | Current assessment |
| --- | --- | --- |
| [alexseveringhaus/market-neural-network](https://github.com/alexseveringhaus/market-neural-network) | The README reports AAPL daily Dense/LSTM/Attention/Ensemble OOS AUC around 0.5 and ensemble paper +0.77% against buy-and-hold +2.38%; it explicitly acknowledges overfitting. Repo SPDX unspecified in public metadata. | Good negative-case research methodology example, **not** a reliable directional oracle or freely licensed code import. |
| [binarymind08/-market-predictor](https://github.com/binarymind08/-market-predictor) | The project README describes FastAPI + WebSockets + React real-time charts and LSTM; yfinance and public demo. No independently source-verified trading results; SPDX unspecified. | Architectural reference only for WebSocket/phone terminal; do not claim broker-grade live feed, predictions, or copy code without a grant. |
| [udityalaad/Stock_Market_Prediction_Using_RNN](https://github.com/udityalaad/Stock_Market_Prediction_Using_RNN) | Original older Keras daily company-stock model with 3 previous-day OHLCV observations and a 70/30 split; description claims >80% accuracy but the repository's metric definitions do not establish net after-cost profits. SPDX unspecified. | Teaching comparison only; no authorized source for Genesis BTC minute-candle training. |
| [taleblou/DecisionTrees-Price-Prediction](https://github.com/taleblou/DecisionTrees-Price-Prediction) | GitHub metadata MIT. README advertises Bitcoin/OHLC R2 ~0.95. **Inspected main.py**: full historical sample is fed to MinMaxScaler.fit_transform before temporal testing, and model.predict receives **Y_test target values** rather than X_test known-at-decision features. | Reject predictor/scored R2; code offers a direct false-success/leakage regression example; not a validated ML component. |
